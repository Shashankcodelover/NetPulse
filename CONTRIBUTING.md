# Contributing to NetPlus CRM

Thank you for contributing to NetPlus!

## Development Workflow
1. Fork the repository and create your feature branch (`git checkout -b feature/amazing-feature`).
2. Make your changes and verify TypeScript & ESLint pass (`npm run build`).
3. Commit using descriptive commit messages.
4. Push to your branch and open a Pull Request.

## Security
Never commit secrets, tokens, or live PostgreSQL Supabase credentials.
